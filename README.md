# DAIOS

## Data Aware Intelligence Operating System

DAIOS is an experimental operating-system and system-intelligence project developed as part of my Operating Systems / CP work.

The project explores Linux process management, system monitoring, resource utilization, and data-aware system intelligence using WSL.

## Objectives

- Understand Linux process management
- Monitor CPU, memory, and system resources
- Explore process states and parent-child relationships
- Build system monitoring utilities
- Implement data-aware system intelligence
- Experiment with OS concepts in a practical environment

## Tech Stack

- Linux
- WSL2
- Python
- Bash
- Git & GitHub
- psutil
